`portc` stands for **Parallel Out-of-Core Randomized Tensor-Network Compression**.
It is a pure-Python implementation of Successive Randomized
Compression (SRC) [@camano2026src], a randomized algorithm that contracts and
compresses tensor trains in a single sweep. It extends the original MPO-MPS
product to MPO-MPO products, plain compression of an MPS or MPO, and whole
stacks of trains.

The package has no tensor-network framework dependency: it takes and returns
plain lists of per-site NumPy arrays, in the `quimb` layout [@gray2018quimb], and
runs on GPUs through CuPy, including multiple GPUs and memory-budgeted
out-of-core execution.

New here? Install the package and run the first example in [Getting
Started](/getting-started), then read [Concepts](/concepts) for the algorithm and
the array conventions.
